# نسخه PHP پنل MikroTik UserManager برای cPanel

این پوشه بازنویسی مستقل پروژه با PHP 8.1+ و MySQL است. برای نصب و اجرا به SSH، Composer، Python، Redis یا Celery نیاز ندارد. فایل ZIP آماده را می‌توانید مستقیماً در File Manager آپلود و Extract کنید؛ نصب دیتابیس و ساخت مدیر از مرورگر انجام می‌شود.

## امکانات

- داشبورد فارسی/انگلیسی و واکنش‌گرا
- مدیریت چند روتر MikroTik با RouterOS v7 REST API
- ساخت، ویرایش، قطع/وصل، تمدید و حذف کاربران PPP روی روتر و پنل
- سرویس‌های PPPoE، PPTP، L2TP و SSTP
- مدیریت پلن، سرعت، مدت اعتبار و قیمت
- صدور خودکار فاکتور، ثبت پرداخت و گزارش درآمد
- پایش نشست‌های آنلاین و تجمیع ترافیک روزانه
- همگام‌سازی کاربران روتر و دیتابیس محلی
- انقضای خودکار کاربران و تشخیص فاکتورهای معوق
- نقش‌های superadmin، operator، billing و viewer
- رمزنگاری رمز روتر و کاربر با AES-256-GCM
- محافظت CSRF، محدودسازی ورود ناموفق، کوئری‌های آماده PDO و گزارش ممیزی

## پیش‌نیازها

- PHP 8.1 یا جدیدتر
- MySQL 5.7+ یا MariaDB 10.3+
- افزونه‌های PHP: `pdo_mysql`، `curl`، `openssl` و `mbstring`
- دسترسی سرور cPanel به IP و پورت REST روتر

نکته مهم: SSH بسته بودن مشکلی ایجاد نمی‌کند، اما سرور هاست باید بتواند به روتر متصل شود. اگر روتر پشت NAT است، دسترسی امن را فقط برای IP خروجی هاست باز کنید. قرار دادن REST API روی اینترنت عمومی بدون فایروال و TLS توصیه نمی‌شود.

## نصب بدون SSH

1. در cPanel وارد **MySQL Databases** شوید.
2. یک دیتابیس و یک کاربر MySQL بسازید و گزینه **All Privileges** را برای آن کاربر روی دیتابیس فعال کنید.
3. در **MultiPHP Manager** یا **Select PHP Version**، نسخه PHP را روی 8.1 یا جدیدتر بگذارید و افزونه‌های لازم را فعال کنید.
4. فایل ZIP را در مسیر دامنه یا زیردامنه، مثلاً `public_html/usermanager`، آپلود و Extract کنید.
5. آدرس `https://example.com/usermanager/install.php` را باز کنید.
6. مشخصات دیتابیس و مدیر اولیه را وارد کنید و دکمه نصب را بزنید.
7. بعد از ورود موفق، فایل `install.php` را با File Manager حذف کنید.
8. از «روترها» یک روتر اضافه کنید، اتصال را آزمایش کنید و سپس همگام‌سازی را اجرا کنید.

اگر نصب‌کننده نتوانست `config.php` را بنویسد، متن آماده آن را نمایش می‌دهد. با File Manager فایلی با همین نام کنار `index.php` بسازید و متن را داخل آن قرار دهید.

## آماده‌سازی RouterOS v7

REST API از سرویس `www-ssl` استفاده می‌کند. روی روتر، گواهی TLS معتبر یا گواهی‌ای که هاست بتواند اعتبارسنجی کند تنظیم کنید. یک کاربر اختصاصی برای پنل بسازید و دسترسی را با فایروال فقط به IP هاست محدود کنید. در محیط واقعی گزینه‌های HTTPS و «بررسی گواهی TLS» را روشن نگه دارید.

اگر از گواهی self-signed استفاده می‌کنید، خاموش‌کردن بررسی TLS اتصال را راه می‌اندازد اما امنیت را کاهش می‌دهد. راه بهتر، نصب یک گواهی معتبر روی روتر است.

## اجرای دوره‌ای بدون SSH

پس از ورود، به **مدیریت ← وضعیت سیستم** بروید. آن صفحه آدرس Cron دارای توکن را نشان می‌دهد.

در بخش **Cron Jobs** cPanel، اجرای هر ۵ دقیقه را انتخاب و این الگو را ثبت کنید:

```text
wget -q -O /dev/null "https://example.com/usermanager/cron.php?token=TOKEN"
```

توکن و آدرس کامل در صفحه وضعیت سیستم آماده کپی است. اگر cPanel بخش Cron Jobs ندارد، همین URL را در یک سرویس Web Cron ثبت کنید. بدون Cron نیز عملیات دستی کار می‌کند، اما وضعیت آنلاین، ترافیک، انقضا و همگام‌سازی خودکار به‌روز نخواهد شد.

## ترتیب راه‌اندازی پیشنهادی

1. افزودن روتر و زدن «آزمون»
2. ساخت پلنی که `mikrotik_profile` آن دقیقاً با نام `/ppp/profile` روی روتر برابر باشد
3. اجرای همگام‌سازی برای ورود کاربران موجود
4. اختصاص پلن به کاربران واردشده، یا ساخت کاربر جدید از پنل
5. فعال‌کردن Cron

## پشتیبان‌گیری و ارتقا

- از دیتابیس با ابزار **Backup** یا **phpMyAdmin Export** پشتیبان بگیرید.
- فایل `config.php` حاوی اطلاعات دیتابیس و کلید رمزنگاری است؛ آن را امن و خارج از دسترس عمومی نگه دارید.
- کلید `encryption_key` را بدون برنامه مهاجرت تغییر ندهید؛ در غیر این صورت رمزهای ذخیره‌شده قابل بازیابی نیستند.
- هنگام ارتقا، `config.php` را نگه دارید و پیش از جایگزینی فایل‌ها از دیتابیس نسخه پشتیبان بگیرید.

## عیب‌یابی سریع

- **خطای اتصال دیتابیس:** نام دیتابیس و کاربر در cPanel معمولاً پیشوند نام حساب دارند؛ مقدار کامل را وارد کنید.
- **روتر پاسخ نمی‌دهد:** IP/پورت، سرویس `www-ssl`، NAT، فایروال و اجازه اتصال خروجی هاست را بررسی کنید.
- **خطای گواهی SSL:** گواهی معتبر نصب کنید؛ خاموش‌کردن Verify TLS فقط برای آزمایش است.
- **ترافیک یا آنلاین‌بودن به‌روز نیست:** Cron را فعال کنید یا از صفحه وضعیت سیستم «اجرای نگهداری اکنون» را بزنید.
- **خطای 500:** گزارش `Errors` در cPanel و نسخه/افزونه‌های PHP را بررسی کنید. برای آزمایش کوتاه می‌توان `debug` را در `config.php` روی `true` گذاشت و بعد دوباره خاموش کرد.
